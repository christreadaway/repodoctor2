Find the reusable parts of your repos.

A components scan reads the file tree of every repo in your latest scan (one GitHub call per repo, no file contents) and looks for path evidence of shared infrastructure: auth, logging, email and SMS, payments, testing, deployment config, Claude docs, design tokens, charts, and more. The result is a map of which repo has which capability and which one is the best source to extract from.

1

Scan

Fetches each repo's file list and matches it against ~20 capability patterns. Vendor folders are skipped.

2

Pick the best source

For every capability, the repo with the most matching files (most recently pushed wins ties) is flagged as the extraction source.

3

Hand it to Claude

Copy the inventory as Markdown and start the extraction work with a full picture of where everything lives.

Evidence is path-based only. A repo that uses a library without a telltale filename will not register a hit.
